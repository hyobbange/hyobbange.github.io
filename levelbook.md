## Features

- Enter backsight (BS), turning point (TP) and intermediate point (IP) readings; instrument height (IH) and ground height (GH) are calculated automatically
- A check row at the bottom verifies the calculation
- Edit column titles to match the names you use
- Keep several field books in a list
- Share a field book as a `.csv` file
