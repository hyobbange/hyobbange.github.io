# 動く人ごみの中から探すゲーム

<p class="lang-switch"><a href="{{ '/oddball/moving-crowd/' | relative_url }}" lang="en">English</a> · 日本語 · <a href="{{ '/oddball/es/moving-crowd/' | relative_url }}" lang="es">Español</a> · <a href="{{ '/oddball/pt/moving-crowd/' | relative_url }}" lang="pt-BR">Português</a> · <a href="{{ '/oddball/ko/moving-crowd/' | relative_url }}" lang="ko">한국어</a></p>

動く人ごみの中から探すゲームは、**探しているあいだも画面が変わる**隠れた物探しです。止まった絵なら一度見たところをもう一度見る必要はありませんが、動く人ごみでは、見終わったところに別のキャラクターが歩いてきたり、探している子が建物のうしろに隠れてまた出てきたりします。だから、**人を目で追わずにエリアを受け持って見る**のが基本のコツです。

| | 止まった絵 | 動く人ごみ |
|---|---|---|
| 画面 | そのまま | キャラクターが歩き回る |
| 隠れたもの | ずっと隠れている | 建物や壁のうしろに隠れては出てくる |
| 見終わったところ | もう見なくていい | 少しあとでもう一度見ることも |
| 有利なところ | ゆっくり見られる | 歩くと横顔や持っているものがよく見える |

人ごみの中からひとりを探す絵本を思いうかべると近いですが、それが動いているイメージです。例は、何百人ものキャラクターの中から**ひとりだけちがう子**を探すゲーム「[へんなやつ探し（Oddball）]({{ '/oddball/' | relative_url }})」からとりました。

## 動く人ごみで見つけるコツ5つ

1. **人ではなくエリアを見る。** ひとりを目で追うと、そのあいだほかのところが見えません。画面を2〜3つのエリアに分けて、一つのエリアにいるキャラクターだけをすばやく見ていきます。
2. **一方向に見て、もう一度もどる。** 見ているあいだに入ってきたり出ていったりするキャラクターがいます。1周目は端から端へ、2周目は反対方向にもどって見ると、見落としが減ります。
3. **建物のうしろは別に確かめる。** 建物や壁のうしろにいるキャラクターは、片側からは見えません。マップを回して反対側から見るか、少し待って歩いて出てくる子を確かめます。
4. **歩くとよく見える特徴をねらう。** 歩くと横顔や持っているもの（ぶき・たて）がよく見えます。まずシルエットや持っているもののように遠くからでも見えるちがいを見て、顔のような小さなちがいはあとで拡大して見ます。
5. **拡大したら、動かずに待ってみる。** 大きく拡大すると、キャラクターがすぐ画面の外に出てしまいます。一か所で少し見ていると、通りすぎるキャラクターを順番に確かめられます。

止まった絵にも使える基本のコツ（まず「ふつう」を覚える、大きなちがいから小さなちがいへ）は、[かくれんぼ・まちがいさがしが上手になるコツ7つ]({{ '/oddball/ja/tips/' | relative_url }})にまとめています。

## へんなやつ探しでの使い方

へんなやつ探しでは、町をうめつくす何百人ものキャラクターが歩き回り、建物や壁のうしろに隠れます。動く人ごみで役立つ機能はこちらです。

| 機能 | 使うとき |
|---|---|
| **拡大・縮小**（2本指） | 遠くからエリアを見て、顔のような小さなちがいは拡大して確かめる |
| **マップを回す**（画面下の左右のボタン） | 建物や壁のうしろに隠れたキャラクターを反対側から見る |
| **ヒント：どこがちがうか** | 探す特徴を一つにしぼって、見る時間を短くする |
| **ヒント：いる場所の近く** | 円で場所を教えてくれます。ターゲットが歩いて円の外に出ると「ターゲットが移動しました」と知らせて、また円を表示します |

ヒントは広告を見るか、ジェムで使えます。早く見つけるほど星3つに近づきます。

## よくある質問

### 探している子も動きますか？

はい。ほかのキャラクターといっしょに歩き回ります。だから場所のヒントも、ターゲットが動くともう一度教えてくれます。

### 建物のうしろに隠れたら見つけられませんか？

マップを回すと反対側から見られます。少し待つと歩いて出てくることもあります。

### 止まった隠れた物探しよりむずかしいですか？

むずかしいというより、やり方がちがいます。一度見たところももう一度見る必要がありますが、歩くとシルエットや持っているものが見えやすいという良さもあります。

### オフラインでも遊べますか？

はい。アカウント不要ですぐに遊べて、オフラインでも動きます。
