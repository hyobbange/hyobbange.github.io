# うずまきステージ攻略

<p class="lang-switch"><a href="{{ '/oddball/swirl/' | relative_url }}" lang="en">English</a> · 日本語 · <a href="{{ '/oddball/es/swirl/' | relative_url }}" lang="es">Español</a> · <a href="{{ '/oddball/pt/swirl/' | relative_url }}" lang="pt-BR">Português</a> · <a href="{{ '/oddball/ko/swirl/' | relative_url }}" lang="ko">한국어</a></p>

[へんなやつ探し（Oddball）]({{ '/oddball/' | relative_url }})のうずまきステージは、**みんながバラバラにまざっているステージ**です。ふつうのステージではみんな同じでひとりだけちがいますが、うずまきでは色・服・顔がみんなちがうので「ふつう」がありません。それでも**ちがう子はひとりだけ**で、見つけ方があります。

| | ふつうのステージ | うずまきステージ |
|---|---|---|
| 人ごみ | みんな同じに見える | みんなバラバラ |
| 探すもの | ふつうとちがうひとり | みんなに共通する特徴をひとりだけ外れている子 |
| 最初にやること | 「ふつう」を覚える | みんなに共通する特徴を1つ見つける |

ポイントはこれです。**みんなバラバラでも、1つの特徴だけはみんな同じで、そこだけちがう子がひとりいます。** だから、ちがいをいきなり探すより、まず「みんなに共通するもの」を探すほうが早いです。結果画面では「ひとりだけまゆげがない」「ひとりだけぶきがある」のように、見つけた子を基準に教えてくれます。

## 探す順番

1. **何人かを選んで「みんな同じところ」を探す。** はなれた場所のキャラクターを5〜6人くらべて、色や服はちがうのにここだけは同じ、というところを探します。それがこのステージの「ちがうところ」です。
2. **あるかないかから見る。** ぶき・たて・まゆげ・毛やツノ・かざりのように、あるかないかで分かれるものは遠くからでも見えるので、いちばん早く確かめられます。みんなぶきを持っているのにひとりだけない、だれも持っていないのにひとりだけある、といったぐあいです。
3. **次は大きな形。** 体・頭・うでの形がみんな同じかを見ます。色がバラバラでまよったら、色は気にせず輪郭だけを見ます。
4. **最後に顔を拡大して見る。** 目の形・目の数・口は遠くからは見えにくいです。拡大してから、エリアごとに見ていきます。

### 知っておくといいこと

- うずまきステージでは、**鼻や頭のかざりがあるかどうかと目の数は、ステージ全体で同じにそろえてあります**（それが「ちがうところ」でないかぎり）。まぎらわしくならないための設定なので、このどれかがちがう子が見えたら、それが答えの可能性が高いです。
- 色や服がちがうのは、うずまきステージではヒントになりません。みんなバラバラだからです。
- 探している子も歩き回って建物のうしろに隠れます。マップを回して建物のうしろも確かめましょう。

## いつ出てくる？

- **どのパックも6・12・18・24・30番のステージ**がうずまきです。1パックに5回で、うしろのステージほどキャラクターが多くなります（70人から170人まで）。
- **今日のチャレンジは土曜日**にうずまきステージになります。チャレンジのキャラクターは90人です。
- うずまきステージが始まると「みんなバラバラにまざっているよ。ひとりだけちがうところをさがそう！」と表示されます。

## 行きづまったときのヒント

- **「どこがちがうか教える」**ヒントは、うずまきステージで特に役に立ちます。みんなに共通する特徴がすぐわかるので、あとはその特徴だけを見ればよくなります。
- **「いる場所の近くを教える」**ヒントは、円で場所を教えてくれます。円の中もバラバラなので、1つ目のヒントといっしょに使うと早いです。

ヒントは広告を見るか、ジェムで使えます。

## よくある質問

### うずまきステージでも、ちがう子はひとりだけ？

はい。ひとりだけで、みんなに共通する特徴がその子だけちがいます。

### 色がちがうキャラクターがたくさんいるけど、全部まちがい？

いいえ。うずまきステージでは、色や服などほかの特徴はもともとバラバラです。まず、みんなに共通する特徴を見つけましょう。

### うずまきステージだけとばせる？

いいえ。ステージは順番に開くので、先に進むにはうずまきステージもクリアする必要があります。行きづまったらヒントを使ってみてください。
