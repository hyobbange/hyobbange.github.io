# Swirl Stage Guide

<p class="lang-switch">English · <a href="{{ '/oddball/ja/swirl/' | relative_url }}" lang="ja">日本語</a> · <a href="{{ '/oddball/es/swirl/' | relative_url }}" lang="es">Español</a> · <a href="{{ '/oddball/pt/swirl/' | relative_url }}" lang="pt-BR">Português</a> · <a href="{{ '/oddball/ko/swirl/' | relative_url }}" lang="ko">한국어</a></p>

A Swirl Stage in [Oddball]({{ '/oddball/' | relative_url }}) is **a level where everyone is mixed up**. In a normal stage everyone looks the same and one is different. In a Swirl Stage colors, outfits and faces all vary, so there is no "normal". Still, **only one character is the odd one out**, and there is a way to find it.

| | Normal stage | Swirl Stage |
|---|---|---|
| The crowd | Everyone looks the same | Everyone looks different |
| What you look for | The one that differs from normal | The one that breaks the feature everyone else shares |
| First step | Learn what "normal" looks like | Find the one feature everyone shares |

Here is the key: **even when everyone is different, one feature is the same for all of them, and only the odd one has it different.** So instead of hunting for the difference straight away, it is faster to first find what everyone has in common. The result screen then tells you from the odd one's side, like "Only one has no eyebrows" or "Only this one has a weapon".

## How to search

1. **Pick a few characters and find what they share.** Compare 5 or 6 characters far apart from each other. Colors and outfits all differ, but look for the one thing that is the same on all of them. That is this level's difference.
2. **Start with has / doesn't have.** Weapons, shields, eyebrows, hair or horns and decorations are either there or not, and you can see them from far away. Everyone has a weapon except one, or nobody has one except one.
3. **Then the big shapes.** Check whether body, head and arm shapes all match. If the mixed colors confuse you, ignore color and look only at outlines.
4. **Finally, zoom in on faces.** Eye shape, number of eyes and mouth are hard to see from a distance. Zoom in and scan one area at a time.

### Good to know

- In Swirl Stages, **whether characters have a nose or head decoration, and how many eyes they have, is kept the same across the whole level** (unless that is the difference). It is set this way to avoid confusion, so if you spot a character that differs in one of these, it is very likely the one.
- Different colors or outfits are not a clue in a Swirl Stage. Everyone is different there.
- The odd one walks around and hides behind buildings too. Rotate the map to check behind them.

## When do Swirl Stages appear?

- **Stages 6, 12, 18, 24 and 30 of every pack** are Swirl Stages. That is 5 per pack, and later ones have more characters (from 70 up to 170).
- **The Daily Challenge is a Swirl Stage on Saturdays**, with 90 characters.
- When a Swirl Stage starts, the game shows: "Everyone is mixed up. Find the one thing only one of them has!"

## Using hints when you are stuck

- **"Tell me what is different"** is especially useful in a Swirl Stage. It tells you which feature everyone shares, so from then on you only need to scan that feature.
- **"Show roughly where it is"** shows a circle around the location. Everyone inside the circle still looks different, so it works best together with the first hint.

Hints are unlocked by watching an ad or with gems.

## FAQ

### Is there still only one odd one in a Swirl Stage?

Yes. There is only one, and it is the one that differs in the feature everyone else shares.

### Many characters have different colors. Are they all wrong?

No. In a Swirl Stage, other features such as color and outfit vary on purpose. Find the feature everyone shares first.

### Can I skip Swirl Stages?

No. Stages open in order, so you need to clear Swirl Stages to move on. Try a hint if you get stuck.
