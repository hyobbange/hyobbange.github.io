# 승강식 야장 기입법: 계산 방법과 예제

승강식 야장은 **앞 측점과의 높이 차이(승·강)를 구해서 지반고를 이어 가는** 레벨 측량 야장이에요. 기계고를 만들지 않고, 바로 앞에 읽은 값과 지금 읽은 값을 비교해요.

<p class="formula">높이 차 = 앞 측점의 읽음값 − 이 측점의 읽음값<br>값이 +이면 승(오름), −이면 강(내림)<br>지반고 = 앞 측점의 지반고 + 승 (또는 − 강)</p>

읽음값이 작을수록 그 점이 높아요. 표척을 세운 땅이 높으면 시준선에 더 가까워서 작은 값이 읽히기 때문이에요. 그래서 "앞 값 − 지금 값"이 +면 올라간 것이에요.

## 야장의 열

열은 [기고식]({{ '/levelbook/ko/height-of-instrument/' | relative_url }})과 비슷하지만 기계고(IH) 대신 **승·강** 두 열이 있어요.

| 열 | 이름 | 뜻 |
|---|---|---|
| BS | 후시 | 레벨을 세우고 처음 본 값 (높이를 아는 점) |
| IP | 중간점 전시 | 같은 자리에서 중간에 본 값 |
| TP | 이기점 전시 | 레벨을 옮기기 전에 마지막으로 본 값 |
| 승 | Rise | 앞 측점보다 높아진 만큼 |
| 강 | Fall | 앞 측점보다 낮아진 만큼 |
| GH | 지반고 | 각 측점의 높이 |

**중요:** 비교하는 "앞 값"은 같은 기계 자리에서 본 값이에요. 레벨을 옮긴 뒤에는 이기점의 **새 후시**가 비교의 시작점이 돼요.

### 1. 첫 기계 자리 (측점 1~4)

측점 1의 후시 0.80에서 시작해서, 바로 앞에 읽은 값과 비교해요.

- 측점 2: 0.80 − 1.33 = −0.53 → **강 0.53**, GH = 11.00 − 0.53 = **10.47**
- 측점 3: 1.33 − 1.42 = −0.09 → **강 0.09**, GH = 10.47 − 0.09 = **10.38**
- 측점 4: 1.42 − 2.43 = −1.01 → **강 1.01**, GH = 10.38 − 1.01 = **9.37**

### 2. 레벨을 옮긴 뒤 (측점 4~6)

측점 4에서 레벨을 옮기고 같은 점을 후시 1.56으로 다시 봤어요. 이제부터는 이 1.56이 "앞 값"이에요. 측점 4의 전시 2.43과 비교하지 않아요.

- 측점 5: 1.56 − 0.74 = +0.82 → **승 0.82**, GH = 9.37 + 0.82 = **10.19**
- 측점 6: 0.74 − 0.33 = +0.41 → **승 0.41**, GH = 10.19 + 0.41 = **10.60**

기고식으로 푼 것과 지반고가 모두 같아요(10.47, 10.38, 9.37, 10.19, 10.60). 방법만 다르고 결과는 같아야 해요.

## 검산하는 법

승강식은 세 값이 모두 같아야 해요.

<p class="formula">ΣBS − ΣTP = Σ승 − Σ강 = 마지막 지반고 − 처음 지반고</p>

- ΣBS − ΣTP = 2.36 − 2.76 = **−0.40**
- Σ승 − Σ강 = 1.23 − 1.63 = **−0.40**
- 마지막 − 처음 = 10.60 − 11.00 = **−0.40**

Σ승·Σ강에는 **중간점의 승·강도 들어가요.** 그래서 중간점에서 빼기를 잘못하면 검산에서 바로 드러나요. 기고식 검산은 중간점을 확인하지 못하는 것과 가장 크게 다른 점이에요. 다만 이것도 계산 실수를 잡는 검산이지, 읽은 값 자체의 오차를 알려 주지는 않아요.

## 기고식과 비교

| | 승강식 | 기고식 |
|---|---|---|
| 계산 | 앞 값 − 지금 값으로 승·강을 구해 더하고 빼요 | 기계고에서 전시를 빼요 |
| 검산 | 중간점까지 확인돼요 | 이기점만 확인돼요 |
| 계산량 | 측점마다 빼기가 한 번 더 있어요 | 중간점이 많아도 빨라요 |
| 맞는 곳 | 정밀하게 확인해야 하는 측량 | 중간점이 많은 종단·횡단 측량 |

두 방식은 같은 읽음값에서 같은 지반고를 내요. 그래서 승강식으로 적은 야장도 같은 BS·TP·IP를 기고식 계산기에 넣어 지반고를 한 번 더 맞춰 볼 수 있어요.

## 자주 하는 실수

- **레벨을 옮긴 뒤에도 이기점 전시와 비교하기.** 옮긴 뒤 첫 비교는 새 후시(예제의 1.56)와 해요.
- **빼는 순서를 바꾸기.** 앞 값 − 지금 값이에요. 거꾸로 하면 승·강이 뒤바뀌어요.
- **검산에서 ΣTP에 중간점 넣기.** ΣTP는 이기점과 마지막 점의 전시만 더해요. 중간점은 Σ승·Σ강 쪽에서 확인돼요.

## 자주 묻는 질문

### 승강식과 기고식의 결과가 다를 수 있나요?

아니요. 같은 읽음값이면 지반고는 같아요. 다르게 나오면 어느 한쪽에 계산 실수가 있는 것이에요.

### 승과 강을 한 열에 +, −로 적어도 되나요?

돼요. 다만 검산할 때 Σ승과 Σ강을 따로 더하기 쉽도록 두 열로 나눠 적는 경우가 많아요.

### 시험에는 어느 방식이 나오나요?

두 방식 모두 나올 수 있어요. 같은 읽음값을 두 방식으로 풀어 보면 서로 확인하기 좋아요.
